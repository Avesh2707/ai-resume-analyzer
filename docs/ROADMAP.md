# Roadmap

This project is being built incrementally, one phase at a time. Each phase is a
complete, runnable project — never a partial or broken state.

## ✅ Phase 1 — Initial Project Setup (current)

- Monorepo scaffold (`client`, `server`, `shared`)
- React + TypeScript + Vite + Tailwind CSS + shadcn/ui frontend
- Express + TypeScript backend
- Single `GET /api/health` endpoint
- Static Home page
- Linting, formatting, path aliases, environment config

## 🔜 Future Phases (not yet implemented)

The following are **explicitly out of scope** until a later phase is requested:

- Authentication (login / register / JWT / protected routes)
- Database integration (e.g. MongoDB)
- Resume upload (file handling, storage)
- AI-powered resume analysis (e.g. OpenAI / Gemini integration)
- User dashboard & profile
- Analysis history
- Chat / conversational features

Each future phase will be delivered as its own complete, downloadable project
build, only after the current phase has been confirmed working.
